**Step 2: Data Manipulation**

``` r
##retain line, station, name, station latitude / longitude, routes served, entry, vending, entrance type, and ADA compliance. Convert the entry variable from character to a logical variable 

nytransit_df <- 
  nytransit_df |> 
  select(line, station_name, station_latitude, station_longitude, route1, route2, route3, route4, route5, route6, route7, route8, route9, route10, route11, entry, vending, entrance_type, ada) |>
mutate(
    entry = recode_values(
      tolower(entry),  # to lower handles mixed case like "NO" or "Yes"
      "yes" ~ TRUE,
      "no"  ~ FALSE,
    ) #recode_values used instead of case_match to fix warning that came up
  )
```

resulting dataset. Are these data tidy?)

This data set (nytransit_df) has the following variables:line, station
name, station latitude / longitude, routes served, entry, vending,
entrance type, and ADA compliance. We first read and tidied the data and
then manipulated it so only the desired columns as mentioned were kept
as well as converting the ‘entry’ variables from characters to logical
variables. The dataset was cleaned in three steps, first is converting
any missing data to ‘NA’, then using the janitor function to standardize
column numbes into snakecase and finally checking the resulting tibble
to see if rows need to be skipped to find there were none. The dimension
as mentioned in the last checking step is 1868 by 19 (1868 rows or
entries by 19 columns or variables). The data is tidy based on all the
steps done above.
